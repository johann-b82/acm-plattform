# Handbuch-Bilder

Screenshots für die In-App-Hilfe. Werden unter `/hilfe/<name>.png` ausgeliefert
und im Hilfetext (`src/hilfe/*.ts`) als `![Alt](/hilfe/<name>.png)` eingebunden.

Echte Aufnahmen des laufenden, getesteten Stands. Welche Datei welche Seite
zeigt, steht in `docs/handbuch-screenshots.md`.
